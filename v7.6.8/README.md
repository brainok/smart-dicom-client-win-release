# SMART DICOM Client for Windows v7.6.8

**[v7.6.8 Windows x64 MSI 다운로드](https://github.com/brainok/smart-dicom-client-win-release/releases/download/v7.6.8/Smart-DICOM-Client.msi)**

- 로그인 화면의 **PC 등록 정보** 버튼으로 PC ID를 복사해 서버 관리자에게 전달할 수 있습니다. 앱이 로그인할 때 저장된 PC ID를 서버로 보냅니다.
- 처음 로그인할 때는 서버 관리자가 발급한 개인 ID와 임시 비밀번호를 사용하고, 안내에 따라 개인 비밀번호를 설정하세요.
- Windows x64용 MSI를 직접 내려받아 실행하세요. MSI는 코드 서명되지 않았으며 Windows에서 알 수 없는 게시자 경고가 표시될 수 있습니다.
