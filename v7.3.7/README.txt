SMART DICOM Client installation package

1. Keep every file and the Client folder together in this folder.
2. Double-click Install-SMART-DICOM-Client.cmd.
3. Install Tailscale if prompted, complete Brainok Network Setup, then the client starts automatically.

The client is installed for the current Windows user under:
%LOCALAPPDATA%\Brainok\SMART DICOM Client
